How to play

Every puzzle gives you a start word and an end word. Fill the middle slot (or slots) to build a chain where each word connects naturally to the next.

As you type, the heat meter shows how close each word is to an accepted answer — the further the fill slides right, the warmer you are.

Press Check sequence once every slot is filled. There is often more than one valid route, so trust your associations.

Accepted routes and verifier notes

The verifier accepts several route trees for each puzzle. Heat uses a small modified GLoVe-style model built from routes, clues, and endpoint co-occurrence, then compares each entry against the closest bridge words for that slot.

Design Notes

Multiple verification trees are better for playability here. A single route makes good associative answers fail for reasons the player cannot infer. The current verifier accepts parallel routes and scores heat by slot using semantic likeness, which keeps the puzzle directed without making it one-answer brittle.

Cryptography is not necessary for this local raw HTML version. It could help later for daily puzzle integrity by hashing accepted routes or signing server-issued puzzles, but it would make the present heat-map feedback worse because the browser needs useful clue data to score guesses.
